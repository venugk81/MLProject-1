Data Vizualization¶

Data visualization is the process of representing data graphically or visually, making complex information easier to understand and interpret. It transforms raw data into visual formats like charts, graphs, maps, and infographics, allowing patterns, trends, and insights to emerge at a glance.

Importance of Data Visualization

  • Improves Understanding
  • Identifies Trends and Patterns
  • Supports Decision Making

What is matplotlib?¶

It is a widely used Python library for creating simple interactive visualizations in the form of plots, charts, and graphs. It is used to create general-purpose plots (line, bar, scatter, etc.)

What is seaborn?¶

It is library built on top of Matplotlib that provides a high-level interface for creating attractive and informative statistical graphics. It is used to create specialized statistical plots (e.g., pair plot, heatmap)

Some common plots created using both matplotlib and seaborn are -

  1. Line Plot - A plot that shows data points connected by a line, commonly used to track changes over continuous intervals like time.
  2. Bar Chart - Plot that represents categorical data with rectangular bars.
  3. Histogram - Shows the distribution of a numerical variable by grouping data into bins and counting the frequency of values within each bin.
  4. Scatter Plot - Displays individual data points on a two-dimensional axis, useful for showing relationships or correlations between two variables.
  5. Pie Chart - A circular chart divided into slices to illustrate proportional parts of a whole.
  6. Box Plot - Helps in Visualizing the distribution, median, and outliers of a dataset.
  7. Heatmap - Matrix-style plot where values are represented by colors, often used to show correlations or densities in two-dimensional data.
  8. Count Plot - A plot that shows the count of observations in each categorical bin using bars.
  9. Density Plot - Plot showing a continuous probability distribution of a numerical variable
  10. Violin Plot - Combination of a box plot and a density plot to show the distribution, median, and spread of the data.

Some common methods can be applied to beautify the charts -

  1. plt.show() - display the plot (removes the summary)
  2. plt.xlabel() - used to give a label to x-axis
  3. plt.ylabel() - used to give a label to y-axis
  4. plt.title() - sets the title at the top of the plot
  5. plt.legend() - adds a legend to the plot to label different plot elements
  6. plt.figure() - sets the size of the plot in inches
  7. plt.grid() - adds grid lines to the plot for better readability
  8. plt.xticks() - customize the appearance of the tick marks along the x-axis
  9. plt.yticks() - customize the appearance of the tick marks along the y-axis
  10. plt.subplot() - create multiple subplots in a single figure for comparing multiple plots
  11. plt.text() - add a custom text at a specific location on the plot
  12. plt.annotate() - adds annotations with arrows pointing to specific plot points
  13. plt.savefig() - saves the plot as an image file (e.g., PNG, JPG, PDF)
